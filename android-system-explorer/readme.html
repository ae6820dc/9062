System Explorer for Android

Download System Explorer APK

One offline app containing System Explorer version 7, sample 1, with depth 65536 and folders 0–9 followed by a–z. Sample 1 opens automatically on launch; there is no sample chooser. Android Back closes an open program dialog or menu first, then puts the app in the background. The additional native Back/Home/Programs/Backup toolbar is omitted. The original light HTML interface and built-in English menu are retained.

Data

Every original HTML file is packaged byte for byte. Each sample has its own stable local HTTPS origin and its original unique IndexedDB name, Program ID and legacy key. The original sample 1 origin and IndexedDB identifiers are preserved, so installing this APK as an update preserves its saves. The app's data is separate from Chrome's website data; existing browser saves are not automatically imported. Updates with the same package and signer preserve app saves. Uninstalling or clearing app storage removes saved data.

Build and tests

Use JDK 21, Android SDK platform 36 and build-tools 36.0.0. From this directory run ./gradlew assembleExplorerDebug assembleExplorerDebugAndroidTest lintExplorerDebug. Run python3 verify-apk.py to verify the signed APK, package identity, one original resource and three unique identifiers. The dedicated GitHub Actions workflow tests sample 1 offline on Android 16, including restart persistence, sample isolation, each maximum depth, password-protected deletion, native Back and the 65536-level jump. Successful tested builds are uploaded and committed to the separate distribution folder. Actual runtime results are in the workflow logs; a test script alone does not establish success.
