System Explorer for Android

Download System Explorer APK

One offline app containing all 12 Explorer programs: version 7, twelve samples, with depth 65536 and folders 0–9 followed by a–z. Choose a sample from the home screen. Android Back closes an open program dialog or menu first, then returns to the sample chooser. The additional native Back/Home/Programs/Backup toolbar is omitted. The original light HTML interface and built-in English menu are retained.

Data

Every original HTML file is packaged byte for byte. Each sample has its own stable local HTTPS origin and its original unique IndexedDB name, Program ID and legacy key. Saves are isolated across all 12 samples. The app's data is separate from Chrome's website data; existing browser saves are not automatically imported. Updates with the same package and signer preserve app saves. Uninstalling or clearing app storage removes saved data.

Build and tests

Use JDK 21, Android SDK platform 36 and build-tools 36.0.0. From this directory run ./gradlew assembleExplorerDebug assembleExplorerDebugAndroidTest lintExplorerDebug. Run python3 verify-apk.py to verify the signed APK, package identity, 12 original resources and 36 unique identifiers. The dedicated GitHub Actions workflow tests all samples offline on Android 16, including restart persistence, sample isolation, each maximum depth, password-protected deletion, native Back and the 65536-level jump. Successful tested builds are uploaded and committed to the separate distribution folder. Actual runtime results are in the workflow logs; a test script alone does not establish success.
