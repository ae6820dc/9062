中文键盘使用说明

  • 输入不带声调的拼音，例如 nihao，然后点击候选词「你好」。也可以用数字键 1–8 选词，或按空格选择当前页的首项。用 v 输入 ü。
  • 词组没有候选时，可以逐个音节输入。点击「中／英」可切换拼音与英文。
  • 左 ⇧ 仅作用于下一个字符，右 ⇧⇧ 在英文模式中切换持续大写。两个按键互不影响，拼音仍按小写查词。
  • ↵ 换行，😁 打开表情面板。「复制」复制文本，「清空」删除文本和本地草稿。
  • 文本在当前浏览器中自动保存。刷新后恢复草稿。「导出」下载带程序编号、保存时间和 Unix 毫秒时间戳的 HTML 文件。
