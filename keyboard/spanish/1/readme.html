Teclado español

Abrir el teclado

  • La distribución QWERTY de España incluye ñ, ç, ¿ y ¡.
  • Usa la fila de vocales acentuadas o pulsa ´ y después una vocal. Para escribir ü, también puedes pulsar ⇧, ´ y u.
  • ⇧ aplica mayúsculas o cambia el símbolo de la siguiente pulsación. ⇧⇧ activa o desactiva el bloqueo de mayúsculas.
  • AltGr permite escribir @, € y otros símbolos. Con 123 puedes ver más símbolos y con 😁 puedes abrir los emojis.
  • El navegador guarda el texto automáticamente. Usa Copiar para copiarlo, Borrar para vaciar el campo y Exportar para descargarlo en HTML.
