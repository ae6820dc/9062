# Unicode 16 standalone Android
Single offline app for unicode/16/sample1.html. The original HTML, appearance, Program ID F705B6D1B3E1325D and storage key 921D54EEBDAEB1B5 are unchanged.
Label Unicode 16. Package io.github.ae6820dc.unicode16single. No native toolbar or internet permission. Independent of Unicode Studio / Unicode 2.
Build: bash build-sdk.sh with JDK and ANDROID_HOME (SDK platform/build-tools 36).
Original fullscreen request is supported by the WebView host. State stored privately in this app.
The source page currently allows lengths 1–128; this APK preserves its actual behavior.
Android 16 runtime checks cover the original ID, 26 sets, 128-character enumeration, playback, exact large ordinal jumps, state reopening and input validation.
