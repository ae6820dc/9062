android-studios/app/src/androidTest

Build source, test resources or configuration for these offline Android applications:

  • Mathematics Studio APK — Ten programs across five calculator families, with the original and Studio II editions; independent history and settings.
  • Unicode Studio APK — All 27 original Unicode programs: versions 1–9, samples 1–3. Animation directions, language sets, Vietnamese support and search remain in the original sources.

Installation: Android 8.0 or newer. Download an APK above, permit installation from your file manager, then open it. These are debug builds; all use separate application IDs and preserve their own storage on compatible signed updates.

For complete build instructions, program descriptions, signing details, browser-data migration, licenses and test limitations, read the project readme. Original web application files are packaged unchanged; this directory contains only Android implementation or test files.
