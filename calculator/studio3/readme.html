Mathematics Studio III

Basic arithmetic

Use the built-in keypad, then press =. The main expression field uses the calculator keypad only, keeping the phone keyboard closed. Examples: 25+37 = 62; (25+37)*2 = 124; 2^10 = 1024.

The xʸ key inserts ^. Exponents must be integers between −10000 and 10000. Powers associate from the right: 2^3^2 = 512. −2^2 = −4, whereas (−2)^2 = 4. Use Advanced functions for fractional exponents and functions.

Ans inserts the previous result: Ans*2 doubles it. Tap a history entry to restore its expression. C clears the input and ⌫ deletes the previous character.

Percentages

% always divides by 100: 15% = 0.15, so 200+15% = 200.15. In the dedicated percentage calculator, enter a base value of 200 and a percentage of 15: percentage of the base value = 30, increase = 230, decrease = 170. Enter numbers only in these fields; a decimal point or comma is accepted. Do not use thousands separators.

Advanced functions

Five subjects are available: algebra and equations, calculus and analysis, matrices, statistics and probability, and number theory. Each offers its original and Studio II editions, embedded in the workbench or in a separate tab. These tools retain their existing calculation engines and saved data.

Studio II includes exact rational arithmetic, high-precision arithmetic and additional mathematical modes. Read the precision and method notes for the selected operation.

Precision, saving and offline use

The basic calculator uses math.js 15.1.0 BigNumber arithmetic with 80 significant digits. Long results and non-terminating decimals are rounded. 0.1+0.2 = 0.3; 9007199254740993+1 = 9007199254740994. Input limit: 512 characters. Time limit: 5 seconds. Calculations run in a separate worker.

The last 40 calculations and the previous result are stored on this device. Ans is replaced by its value when an expression is saved to history. TXT exports include the Program ID, timestamp, expression and result. Clearing browser data removes local history.

After the first successful offline save, the basic calculator works offline at the same page address. Advanced tools retain their existing offline support; they are not bundled into the basic calculator cache.
