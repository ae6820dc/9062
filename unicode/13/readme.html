Unicode Version 13

An independent version of the Random Text Generator based on Unicode Version 2. The maximum word length is now 128 Unicode characters. Minimum word length works as before, and the default range remains 1–50.

All 26 languages and Unicode mode are available. Seed handling, pagination, copying, UTF-8 HTML export, and light/dark themes are preserved. Settings and theme are saved locally in the browser.

The three standalone samples behave identically. Each has its own 32-character hexadecimal Program ID (also included in HTML exports) and its own 16-character hexadecimal localStorage key, so their saved settings are independent.
