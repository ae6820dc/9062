Hex Byte Explorer — 15/2

This edition extends the 24 samples in explorer/15/1/.

Folder choices

Open Game and enter an 18-digit game ID. Each branching level then offers 264 folders, including 256 byte values (00–FF), four player folders (Player0–Player3), and four result folders (R0–R3). Result folders end the branch and can contain virtual files. The depth limit is 65,536 levels after the game ID.

Operation and data

Enter two hex digits to open a byte folder. The explorer supports grid and list views, folder reordering, and HTML export. Each sample has its own 16-digit hexadecimal Program ID, storage key, and IndexedDB database name. The edit password is 1111.
