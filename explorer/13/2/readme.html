Chess Explorer 2

Open sample1.html

The root is Game, followed by 18 digit folders (0–9), then up to 65,536 chess levels.

At every chess level, the 64 square folders (a8–h1) and four player folders (Player0–Player3) remain available. Four additional result folders can terminate a branch at any level:

R0 · R1 · R2 · R3

Result folders are terminal: no further subfolders appear inside them. You may still create named files there. The meaning of the four result labels is user-defined.

Version 2 uses its own Program ID and separate IndexedDB storage. The original Chess Explorer 1 is unchanged.
