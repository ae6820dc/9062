Explore

Each folder offers a–z until level 8192. Use Back, Forward, Up, the root button, breadcrumbs or a path such as /a/p/b. A–Z opens folders; Alt + arrows navigates. New file creates a virtual file by name at every level, including level 8192. Names may contain accented letters and up to 255 characters. Virtual files do not contain document text or execute programs.

Menu

  • New game: enter 1111 to remove all files and reset location and view in this sample.
  • Delete files: select files in the current folder, then enter 1111. Other folders and samples remain unchanged.
  • Share website: shares this sample's URL without saved data.
  • About: program details and the sample's own Program ID.

Independent saves

Every sample has a unique Program ID, IndexedDB database and legacy migration key. All 36 identifiers also differ from versions 1 and 2. Versions 1 and 2 and their existing saves remain unchanged. Version 3 starts with separate, empty saved games and does not import data from versions 1 or 2. Files are stored as individual IndexedDB records and loaded for the current folder.

Save data is local to this browser and device. Independent databases isolate data, while the browser's storage quota is shared by the website. Capacity depends on browser and device. The menu password is a convenience guard, not encryption.
