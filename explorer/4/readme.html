Explore

Each folder contains a–z until level 65536. Use Back, Forward, Up, root or breadcrumbs. Enter an exact path in the address bar, for example /a/p/b. A–Z opens folders; Alt + arrow keys navigates. Grid and list views are available.

For deep paths, the breadcrumb shows the last 24 folders. Click … to jump to any earlier level on the current path, including level 0 (root). The address bar always contains the full path; Copy path copies it in full.

Files and menu

New file creates a virtual file using only a name, including at level 65536. Names can include accented letters and have up to 255 characters. Files contain names only, not document contents or executable programs.

  • New game: enter 1111 to remove all files and reset this sample's location and view.
  • Delete files: select files in the current folder and enter 1111. Other folders and samples remain unchanged.
  • Share website: shares this sample's URL without saved files.
  • About: program information and the sample's own Program ID.

Independent saves

All 12 samples have unique Program IDs, IndexedDB names and legacy migration keys. All 36 identifiers also differ from versions 1–3. The earlier versions and their saves remain unchanged. Each new sample starts with an empty saved game.

Files are stored as separate IndexedDB records and loaded for the current folder. Data is local to this browser and device. The website's storage quota is shared across samples; capacity depends on browser, device, filename length and path length. The menu password guards interface actions; it is not encryption.
