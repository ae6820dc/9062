Alphabet Explorer — 4/3

Expanded edition of explorer/4/2/. The original 24 samples remain unchanged.

Folder choices

26 English letters (a–z), five extra characters (␣, ., ,, !, ?), four Player folders (Player0–Player3), and four result folders (R0–R3) give 39 choices at each branching alphabet level. Result folders end the branch and can contain virtual files.

Space appears as ␣ (U+2423 OPEN BOX), but its actual folder value is a space (U+0020).

Operation and data

The original 65,536 alphabet levels, game ID navigation, file handling, export and editing features are retained. Each of the 24 expanded samples has its own 16-digit hexadecimal Program ID, storage key and IndexedDB database name, separate from the original edition. Edit password: 1111.
