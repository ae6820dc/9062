Folders and navigation

Each nonterminal folder contains exactly 28 child folders. Character set: ابتثجحخدذرزسشصضطظعغفقكلمنهويءآأإؤئىةًٌٍَُِّْٰٓ٠١٢٣٤٥٦٧٨٩،؛؟٪. Maximum depth is 65,536; the last level has no child folders and still supports files. Arabic glyphs are isolated for right-to-left display while slash-separated paths and breadcrumbs retain their logical root-to-leaf order.

Click a folder or use its character key. Enter slash-separated paths such as /ا/ب/ت in the address field. Copy path copies the complete path. Back, Forward, Up, Home and the drive button navigate; Alt+Left, Alt+Right, Alt+Up and Backspace are supported outside inputs and dialogs. Grid and list views show the same folders and files. Breadcrumbs show the last 24 components; their ellipsis opens Jump to level for an ancestor of the current path.

Files and menu

New file creates a name-only virtual file at the current location. Names contain 1–255 Unicode characters after trimming and NFC normalization, excluding slashes, control characters, . and ... Duplicate names are case-insensitive; child-folder names are reserved. Files have no contents and cannot run programs.

The menu contains New game, Delete files, Share website and About. Delete files offers selection and Select all for the current folder. New game removes all files and resets position and view for this sample. Both require password 1111, an accidental-deletion guard. Share website shares only the website URL. About shows the program name and ID.

Saving

Position, view and files save automatically in IndexedDB on this browser and device. History is session-only. Legacy localStorage saves are validated and migrated transactionally; invalid saves are retained. Storage failures show a reload notice. Each sample has an independent database named by its storage key. Clearing browser data removes saves. Use a modern browser with IndexedDB; HTTP/HTTPS hosting is recommended. All samples are self-contained and use the baseline responsive layout for desktop and mobile screens.

Verification

Run node explorer/10/test.cjs from the repository root with Playwright and Chromium installed (default executable: /usr/bin/chromium; override with CHROMIUM_PATH). The shared suite checks all 44 samples, baseline interface elements, unique IDs, deterministic character sets, navigation, files, saved state, menus, maximum depth and alternating desktop/Android-sized touch viewports. Mobile checks emulate the viewport and touch input; they do not run on a physical Android device.

60-character modern Arabic practice set

28 base letters, 8 additional letter forms, 10 combining vowel/recitation marks, 10 Arabic-Indic digits, and 4 punctuation signs. The combining marks are shown on a dotted circle (◌) in folder labels to make them visible; their actual folder names remain single Unicode characters. This is a practical learning-oriented subset, not all Unicode Arabic characters and not a CEFR C2 proficiency certification.
