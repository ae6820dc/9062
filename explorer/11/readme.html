Character set and navigation

Every level has exactly 18 folders in this fixed order: 0123456789ABCDEFU+. Maximum depth: 65,536. The last level has no child folders. All 18 folder buttons are rendered directly, without virtual scrolling.

Unicode code point notation can be constructed as a path, for example /U/+/0/6/2/7 for U+0627. The Explorer permits any combination of its 18 symbols, so not every path represents a valid Unicode code point.

Features

Use the folder buttons, address bar, breadcrumbs, Up, Back, Forward, Home, and grid/list controls to navigate. The browser saves the current path and user-created virtual file names in IndexedDB. Samples have separate 16-character hexadecimal Program IDs and storage keys.

Performance

Only the current folder's 18 child folders are rendered. Earlier folders are not created as a complete tree. The application retains navigation history for Back and Forward and can store user-created virtual file names.
