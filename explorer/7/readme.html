Navigation

Use Back, Forward, Up, root, breadcrumbs or a full path such as /0/a/9/z. Uppercase letters in the address bar are converted to lowercase. Press 0–9 or A–Z to open a folder; Alt + arrow keys navigates. Grid and list views preserve the digits-first order.

The breadcrumb shows the last 24 folders for deep paths. Click … to jump to an earlier level on the current path, including 0 (root). The address bar and Copy path retain the full path.

Files and menu

New file asks only for a name, with an optional extension. It works at every level, including 65536. File names may include accented letters and up to 255 characters. Files are virtual name entries, not document contents or executable programs.

  • New game: enter 1111 to remove all files and reset this sample's position and view.
  • Delete files: choose files in the current folder, then enter 1111. Other folders and samples remain unchanged.
  • Share website: shares this sample's URL without saved data.
  • About: System Explorer information and this sample's Program ID.

Independent saves

Each sample has a unique Program ID, IndexedDB name and legacy migration key. All 36 new identifiers differ from versions 1–6 too. New samples start empty. Earlier versions and saves remain unchanged. Files are stored separately in IndexedDB and loaded per folder.

Saved data stays in this browser on this device. Samples share the website's storage quota, which depends on browser, device and record sizes. The menu password guards interface actions; it is not encryption.
