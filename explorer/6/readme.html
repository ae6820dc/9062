Navigation and files

Use Back, Forward, Up, root, breadcrumbs, or a complete path such as /a/ő/ű. Uppercase and decomposed accented input in the address bar are normalized to lowercase composed letters. Type one of the 35 letters to open its folder; Alt + arrow keys navigates. Grid and list views are available.

At deep levels, breadcrumbs show the last 24 folders. Click … to jump to any earlier level on the current path, including 0 (root). The full path remains in the address bar and Copy path.

New file asks only for a name, with an optional extension, and works at every level including 65536. File names remain free text with up to 255 characters. These are virtual name entries, not document contents or executable programs.

Menu

  • New game: enter 1111 to remove all files and reset this sample.
  • Delete files: select files in the current folder and enter 1111. Other folders and samples stay unchanged.
  • Share website: shares this sample's URL without saved data.
  • About: Hungarian Explorer details and the sample's Program ID.

Saved data

Each sample has a unique Program ID, IndexedDB name and legacy migration key, all different from versions 1–5. The 12 new samples start empty. Earlier versions and their saves remain unchanged. Files are individual IndexedDB records loaded per folder.

Data is local to this browser and device. Samples share the website's storage quota, whose size depends on browser and device. The menu password guards interface actions; it is not encryption.
