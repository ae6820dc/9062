Explore and create files

Each folder offers the letters a–z, down to level 128. Use Back, Forward, Up, the root button or a breadcrumb to navigate. You can also enter a path such as /a/p/b in the address bar. Press A–Z to open folders or Alt + arrow keys to navigate. Grid and list views are available.

New file asks only for a name, including an optional extension. Names can contain accented letters and have up to 255 characters. Files are virtual name entries, not executable programs or document contents. The same name may exist in different folders or samples; duplicates within one folder are rejected.

Menu

  • New game: password 1111; removes all files and resets location and view in the current sample only.
  • Delete files: select files in the current folder, then enter 1111. Other folders and samples are unchanged.
  • Share website: shares the current sample's website URL, without saved files.
  • About: program information and the sample's Program ID.

Saving

IndexedDB stores files as separate records. Opening a folder loads that folder's records. Each sample uses a distinct database and migration key; sample1 retains its original identifiers and existing saves. A valid older localStorage save is migrated transactionally on first use and removed only after migration succeeds.

Independent databases isolate data, but samples on the same website still share the browser's storage quota. Capacity depends on the browser and device. Data is local to the current browser profile and device. The password protects menu actions in the interface; it is not encryption.
