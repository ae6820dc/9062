# Unicode 14 standalone Android
Single offline APK for unicode/14/sample1.html, bundled byte-for-byte unchanged.
Name Unicode 14. Package io.github.ae6820dc.unicode14single. Original Program ID 84ABE3DBF8C23C7C059E633757F96E7C; storage E575C375A80632A5.
No native toolbar, no Internet permission. Separate from Unicode 16 and Unicode Studio.
Original character/codepoint boxes, search dialog, Vietnamese, playback and saved state are preserved. Fullscreen is supported; Android Back closes search.
Build: bash build-sdk.sh with JDK and Android SDK platform/build-tools 36.
Android 16 offline tests validate the above interactive behavior and persistence.
