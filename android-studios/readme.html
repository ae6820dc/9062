Offline Android applications

  • Mathematics Studio APK — Ten programs across five calculator families, with the original and Studio II editions; independent history and settings.
  • Unicode Studio APK — All 27 original Unicode programs: versions 1–9, samples 1–3. Animation directions, language sets, Vietnamese support and search remain in the original sources.

Install

Android 8.0/API 26 or newer, targeting Android 16/API 36. Download an APK, permit installation from your chosen file manager/browser, and open it. These are installable debug builds with a stable, public test certificate, not private-key production releases. New package IDs let all three studios coexist with each other and the older Unicode APKs. No internet permission is requested. Android status and navigation bars remain visible; immersive/fullscreen requests are declined. Portrait and landscape use system-bar, cutout and keyboard insets.

Use

Back, Home, Programs and Backup stay above the WebView. Home groups calculator families or Unicode versions; Programs switches directly from the current program. Credit Chess opens its original Desktop/Tablet chooser. Existing internal web navigation and controls remain available. The host saves original application state before switching where a save function exists. File import/export uses Android's document picker. Large host downloads/imports are limited to 32 MB; the existing Credit Chess backup limit remains 20 MB/10,000 games.

Storage and migration

These are new apps with new package IDs, separate from Chrome and all previous APKs. Existing browser or APK data is not automatically read, overwritten, or deleted. Each calculator edition and Unicode sample has its own stable local HTTPS origin. Credit Chess Desktop and Tablet intentionally share one origin and the same accounts/games. Updates signed with the same checked-in test certificate preserve this app's data; install over the app with adb install -r. Uninstalling or Android “Clear storage” removes its data.

Calculators: export using the original calculator's backup control in your browser. Open the matching calculator and edition in Mathematics Studio, expand its backup section, and import that JSON with Android's file picker. Do not import an Original backup into Studio II: their original Program IDs and schemas differ.

Credit Chess: in the existing browser app, use Preferences & backups to export JSON or an encrypted backup. In the Android app choose either board, open the same settings, and import the file (and password if encrypted). The original validation, conflict handling and recovery behavior is preserved. Keep the source backup until you have checked profiles, balances, games, clocks and Arena history.

Unicode: versions 3–9 retain their original save functions and storage keys. Versions 1–2 originally had no saved-state API; only the Android host adds isolated persistence of their seeded generator controls under __studio_generator_form_v1. To migrate a current browser sample, open it in a desktop browser, open Developer Tools → Console, and run the following export snippet. It does not change browser storage or the original files. Transfer the resulting JSON to Android, open the matching version/sample, then choose the native Backup → Import local state. Import requires explicit confirmation; export existing app state first if you want to retain it.

(() => {
  const m = location.pathname.match(/\/unicode\/([1-9])\/sample([123])\.html$/);
  if (!m) throw Error('Open a Unicode version 1–9 sample first');
  const values = {};
  if (typeof STORAGE_KEY !== 'undefined') {
    const saved = localStorage.getItem(STORAGE_KEY);
    if (saved !== null) values[STORAGE_KEY] = saved;
  } else {
    values.__studio_generator_form_v1 = JSON.stringify(Object.fromEntries(
      [...document.querySelectorAll('input[id],select[id],textarea[id]')]
        .map(el => [el.id, el.value])));
  }
  const program = `unicode-${m[1]}-${m[2]}`;
  const blob = new Blob([JSON.stringify({schema:1,program,localStorage:values})],
    {type:'application/json'});
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob); a.download = program + '-state.json'; a.click();
  setTimeout(() => URL.revokeObjectURL(a.href), 10000);
})();

The native Backup export/import controls save localStorage for only the current program. They do not export Credit Chess IndexedDB; use Credit Chess's original full backup controls instead. No migration between different editions, samples, or application IDs is performed silently.

Build and verification

Install JDK 21, Android SDK platform 36 and build-tools 36.0.0; set ANDROID_HOME; run android-studios/build-apks.sh from the repository root. Gradle 8.13 and Android Gradle Plugin 8.13.0 are pinned. All original resources are copied at build time and verified byte for byte against the actual APKs. The Stockfish gzip source archive uses an internal .bin suffix to prevent AAPT from automatically decompressing it; the local handler maps the original URL to those unchanged bytes.

The matching GitHub Actions workflow builds, verifies, uploads artifacts, and commits the actual APKs and checksums to this separate distribution folder. Existing APK paths, Factorial Studio, original HTML/JS/CSS, repository indexes and GitHub Pages files are not replaced. Every new source folder has this documentation; resource readmes are filtered out of compiled Android resources.

Run python3 android-studios/package-browser-tests.py with Python Playwright, Chromium and OpenSSL installed for tests against APK-extracted files. Build native test APKs with the assemble*DebugAndroidTest tasks, then run android-studios/android-tests.sh on a dedicated emulator. It changes test preferences, enables airplane mode, and tests separate process invocations in portrait and landscape. The workflow's manual android_tests option runs that suite on an Android 16 emulator. Do not infer success from the existence of a test script; actual executed results and limitations are recorded in VERIFICATION.md.
